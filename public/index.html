CuminDB Genomic Repository

An integrated computational genomics portal for Cuminum cyminum (Cumin). CuminDB compiles contig-level draft assembly GFF annotations, OmicsBox/Blast2GO functional mappings, SSR microsatellite PCR primers, transcription factor classifications, psRNATarget miRNA targets cross-referenced with miRBase, and JBrowse 2 database integrations.

SequenceServer Web BLAST Search Engine

How SequenceServer Works

SequenceServer provides a local, rapid BLAST interface pointing to our database indexes. Query databases are built using makeblastdb -in cumin_predicted_cds.fasta -dbtype nucl and makeblastdb -in cumin_predicted_protein.fasta -dbtype prot. The local alignment search is run directly using the SequenceServer daemon.
